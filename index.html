Overview

I value structure, and I stay with a problem until it is solved. I prefer work that ends in a tangible improvement over work that only describes one.

I want to understand how something works in practice before I change it. Years in a warehouse taught me how quickly a small bottleneck becomes a costly one.

I care about incentives. A good measure should change behavior, not just record it.

I hold a BSc in Business Administration from Lund University and spent an exchange semester in Singapore. I started in Tetra Pak's warehouse and moved into analytical roles in the supply network.

    • Automating a quality workflow

      Tetra Pak, Supply Network Quality, Jun to Sep 2026

      Managing a quality deviation required jumping through five SAP transactions and repeatedly re-entering part and supplier numbers. On my own initiative, I built a script in Python and SAP GUI that unified the procedure into a single prompt.

      Start / end Manual input SAP step Script
      Quality issue identified
      Input 1 Open SAP screen 1 and enter the part number
      SAP screen 1 Update the part's quality setting
      Input 2 Open SAP screen 2 and re-enter the part number
      SAP screen 2 Set up the inspection
      Input 3, lookup Open SAP screen 3, enter the part number and note the supplier number
      Input 4 Open SAP screen 4 and type in the supplier number
      SAP screen 4 Log an inspection for incoming stock
      Input 5 Open SAP screen 5, re-enter the part number and type the reason
      SAP screen 5 Record the reason for the change
      Procedure completed

      5 manual inputs, 5 SAP screens, many chances to mistype

      Quality issue identified
      Single prompt, Python Enter the part number and the reason once
      Predefined process, SAP GUI script Runs in the background
      1. Update the quality setting 2. Set up the inspection 3. Fetch the supplier number 4. Log the incoming inspection 5. Record the reason
      Procedure completed

      1 manual input, no retyping, about 40 minutes saved a day

      I tested it through several iterations before my colleagues started using it daily. It saves about 40 minutes a day, an estimated SEK 80,000 a year.
